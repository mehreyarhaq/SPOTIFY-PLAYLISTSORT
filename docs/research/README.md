# Research

Three research passes were run on 2026-10-14/15 before any code was written. Each report lists
its sources and dates; "unverified" marks claims that rest on secondary sources only.

- `r1_spotify_api.md` — what a new Spotify Development-Mode app can still do in late 2026.
- `r2_genre_sources.md` — where per-track (per-remix) EDM genre labels come from; Beatport taxonomy.
- `r3_audio_ml.md` — audio models and published results for fine-grained EDM subgenre and "feel".
- `reference/` — raw files saved during research (taxonomy dictionaries, crosswalk CSVs, API schemas,
  working auth examples). Third-party content; see each file's header for origin.
